# Mocky Mail 0.11.1

A connections release: company Exchange servers, and Mocky Mail working
with your scripts and AI tools.

Version 0.11.0 with a fix that lets the macOS installer build. Everything below is
new since 0.10.0.


One line for the update notice (`latest.json`):

> Exchange Server accounts, a command line and an MCP server for AI tools, and a command palette.

## Exchange Server

- Add an account on your organisation's own Exchange Server: mail,
  calendar, contacts, free/busy for Find a Time, and automatic replies.
  Mocky Mail finds the server from your address; you can enter it yourself
  if needed. (Microsoft 365 and Outlook.com accounts keep using Continue
  with Microsoft.)
- Exchange tasks aren't synced yet, and changing one date of a repeating
  Exchange event isn't possible yet.

## Microsoft 365 organisations

- When your organisation lets only an administrator approve new apps,
  Mocky Mail now says so plainly, opens the approval page for your
  administrator, or gives you a message to send them, then lets you try
  again.

## Scripts and AI tools

- Settings › Automation lets programs on your computer work with your
  mail: Off (the default), Look only, or Full access.
- The new `mocky-mail` command line comes with the app: list and read
  mail, search, send, or run any of Mocky Mail's commands.
- `mocky-mail mcp` is an MCP server, so AI tools such as Claude Desktop can
  read, search and (with Full access) send and organise your mail. Settings
  › Automation shows the configuration to paste into your MCP client.
- Programs connect only on this computer, with a secret only you can read;
  reset it any time. See docs/automation.md.

## Also

- A command palette: press Ctrl+K (Cmd+K on a Mac) to jump to any folder,
  screen or action by typing.
