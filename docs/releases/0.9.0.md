# Mocky Mail 0.9.0

A files release: bring your mail, calendars and contacts in from other
programs, and take them out again.

One line for the update notice (`latest.json`):

> Import and export mail, calendars and contacts, and bring in Outlook .pst files.

## Import and export

- Import `.eml` and `.mbox` files into any folder, and save a folder as an
  `.mbox` file or selected messages as `.eml` files in a `.zip`.
- Import `.ics` calendar files into a calendar, and save a calendar as an
  `.ics` file.
- Import `.vcf` contact files, and save your contacts as one `.vcf` file.
- Find it all in Settings › Import and export, and in the menus of
  folders, calendars, contacts and selected messages. Long imports show
  their progress and end with a summary of what came in and anything left
  out.

## Outlook

- Bring in an Outlook `.pst` file: its mail goes into a new folder,
  "Imported from Outlook", on the account you choose, and its contacts and
  calendar go to that account's address book and calendar. You can close
  the window while it works; Mocky Mail tells you when it's done. Tasks
  and notes in the file come in a later update.
- `winmail.dat` attachments sent from Outlook are opened up, so you see the
  files inside them.

## Opening files

- Open `.eml`, `.ics` and `.vcf` files with Mocky Mail from your computer,
  or share them to it on Android. A message opens to read, reply to or add
  to a folder; calendar and contact files offer to add what's in them.

## Also

- Mail in older character sets (Cyrillic, Central European, Japanese,
  Chinese, Korean and more) shows correctly.
- Importing an `.ics` file into a Microsoft 365 calendar isn't possible yet;
  use another calendar for now.
